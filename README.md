## Remplacer les vidéos
Les vidéos de démonstration sont chargées depuis `public/videos/` :
- `site-demo-1.mp4`
- `site-demo-2.mp4`
- `site-demo-3.mp4`

Pour changer une vidéo, garde simplement le même nom de fichier et remplace le fichier MP4. Tu peux aussi modifier les titres/descriptions dans `app/page.tsx`.

Les visuels de portfolio sont définis en haut de `app/page.tsx` dans `images` et peuvent être remplacés par tes propres URLs.

## Démarrage
```bash
npm install
npm run dev
```
